SilerChef — photo workflow for the web team (Duygu Hanim / client)

Source folder in this repo:  silerchef.com pictures /   (raw exports from the client)

Regenerate deployable images (classify, copy, renumber, hero/thumb):

  npm run photos

The script copies all JPGs into embed/images/.../gallery/ as 01.jpg, 02.jpg, …
and sets hero.jpg + thumb.jpg from 01. It also copies WhatsApp business card
to embed/images/brand/business-card.jpg when that file exists in the repo root.

Classification uses filename keywords (e.g. pasta → Italian, smoked meat →
American, most cakes/pastry → French) and moves a few items from the large
French set into anniversary, Turkish, and Middle Eastern folders so no section
stays empty.

In the browser, the detail panel loads up to 99 gallery images per folder.

--- Matching photos to cuisines and to section headings (blocks) ---

EN:
- Automated bucket: filenames in silerchef.com pictures / are classified into
  embed/images/cuisines/<slug>/gallery/ via scripts/distribute-photos.mjs.
- Manual tweak: replace or reorder 01.jpg, 02.jpg, … inside a cuisine folder,
  then re-run npm run photos only if you are regenerating from the source folder.
- Detail sheet headings come from embed/data.js: each cuisine or service entry has
  `blocks`: every block has `title` (the heading), `image` (thumbnail beside it),
  and `items`. Set `image` to a gallery path such as cuisineBlockImage(slug, N) or
  a full URL — order of blocks maps 1:1 to headings on the site.
TR (özet):
- Fotoğraflar klasörlere classify() ile veya doğrudan embed/images/cuisines/…/
  gallery/ altında 01.jpg, 02.jpg sırasıyla yerleştirilir; npm run photos bu
  yapıyı kaynak klasörden yeniden üretir.
- Mutfağa (cuisine) özel küçük resim ve galeri: ilgili slug klasörü.
- “Başlıklara dağıtmak”: embed/data.js içindeki blocks dizisi — her elemanın
  `title` metni başlık, `image` alanı o başlığın yanındaki fotoğraf yoludur;
  sıra, sitedeki blok sırasıyla aynıdır.
