SilerChef — photo workflow for the web team (Duygu Hanim / client)

Source folder in this repo:  silerchef.com pictures /   (raw exports from the client)

Regenerate deployable images (classify, copy, renumber, hero/thumb):

  npm run photos

The script copies all JPGs into embed/images/.../gallery/ as 01.jpg, 02.jpg, …
and sets hero.jpg + thumb.jpg from 01. It also copies WhatsApp business card
to embed/images/brand/business-card.jpg when that file exists in the repo root.

Classification uses filename keywords (e.g. pasta → Italian, smoked meat →
American, most cakes/pastry → French) and moves a few items from the large
French set into anniversary, Turkish, and Middle Eastern folders so no section
stays empty.

In the browser, the detail panel loads up to 99 gallery images per folder.
